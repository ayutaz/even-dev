# GarbageCue

Even G2向けのごみ出し確認アプリです。

## MVP

- 曜日ごとのごみ収集種別を最大2つまで登録
- 今日の収集内容と、次回の収集予定を表示
- 設定はブラウザの `localStorage` に保存
- G2では曜日リストを上下スクロールして内容を確認
- ダブルクリックでG2のページを終了

初版では自治体データ、祝日・振替収集、位置情報、通知、外部通信は扱いません。表示される収集予定はユーザーが登録した設定に基づくものです。

## Run

```bash
npm install
npm run dev
```

またはリポジトリのルートから、アプリ選択時に `garbage_cue` を指定して起動します。
